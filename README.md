## 🌟 Featured Project

### 🎮 World of Warcraft Launcher

One of my largest projects so far is a custom **World of Warcraft Launcher built with Python**.

What originally started as a simple alternative way to launch the game grew into a much larger desktop application.

### Features

- Multiple World of Warcraft versions
- Automatic game installation detection
- Version-specific addon management
- Character / Armory viewer
- Saved characters
- Guild information
- Achievement and statistics pages
- Playtime tracking
- News aggregation
- In-app article reader
- Update detection
- Custom themes for each game version
- Windows, macOS, and Linux builds
- Automated GitHub Actions builds

[![WoW Launcher](https://img.shields.io/badge/View_WoW_Launcher-Repository-blue?style=for-the-badge&logo=github)](https://github.com/frankrosello/wow_launcher)
